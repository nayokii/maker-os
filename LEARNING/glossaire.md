# Glossaire MAKER OS

| Terme | Définition simple | Vu en |
|---|---|---|
| Terminal | Fenêtre où l'on donne des ordres à l'ordinateur en les écrivant (PowerShell sous Windows). | 1.1 |
| Commande | Un ordre écrit dans le terminal, ex. `node --version`. | 1.1 |
| Option / flag | Réglage d'une commande, précédé de `--` (ex. `--version`). | 1.1 |
| Node.js | Programme qui exécute du JavaScript hors du navigateur. Nos outils (Vite, TypeScript) en ont besoin. | 1.1 |
| npm | Gestionnaire de paquets livré avec Node (équivalent de pip en Python). | 1.1 |
| Paquet | Code écrit par d'autres qu'on réutilise (React, Vite, Dexie...). | 1.1 |
| Courant (LED) | C'est le courant non limité, pas la tension seule, qui grille une LED sans résistance. | Test de départ |
